# 🎨 Module M1: React Project Setup & Basic Layouts

This repository contains **Module M1 (React Project Setup + Basic Layouts)** for the SyncSpace collaborative workspace platform.

---

## 🛠️ Module Overview

- **Module Code:** `M1`
- **Focus Area:** React 18 Application Setup, Vite Configuration, Global Styling System, Navigation Header, Resizable Split Layout Container, and UI Shell Architecture.
- **Tech Stack:** React 18, Vite, CSS Layouts (Flexbox & Grid), Lucide React Icons.

---

## 📁 Layout Component Architecture

- `client/src/App.jsx` — Primary Application Shell & Layout Container Wrapper
- `client/src/components/Header.jsx` — Top Bar Navigation Header Layout & Workspace Controls
- `client/src/components/SplitLayout.jsx` — Dynamic Resizable Split-Pane Layout Container
- `client/src/components/JoinRoomModal.jsx` — Initial Room Connection Modal Layout
- `client/src/index.css` — Modern Glassmorphism & Light/Dark Responsive Design Token Styles

---

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation & Development Server

```bash
# 1. Navigate to the React Client directory
cd client

# 2. Install dependencies
npm install

# 3. Start Vite Development Server
npm run dev

# 4. Build for Production
npm run build
```
